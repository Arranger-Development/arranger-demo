# 深秋素材接入记录

来源：[音乐素材 / 深秋 #Cm BPM 100](https://app.notion.com/p/3e4d48cb1eee80e9bb35e601abdd7533)。本轮只在本地提交，未推送或发布。

## 使用

1. Live → 编辑／保存段落，每轨六个主槽、两个转场槽。旧模板优先，空缺按素材创建顺序补齐。
2. 方块下拉只列对应轨道、对应类型的真实模板；十个未提供占位仍禁用。替换不触发声音，也不改变已保存段落或 Live 副本；点击方块才使用新绑定。
3. 点击鼓／和弦轨道图标，选择“深秋鼓组”／“深秋和弦”。原默认音色保留。保存段落后将素材放入 Live，音色随副本和创作导出保留。
4. 键盘四排：`1–8`、`Q–I`、`A–K`、`Z–,`。前六主槽、后两转场；Launchpad 同步八槽，保留原段落分页、保存、停止键。
5. 旧十加四绑定按类别保留前六主槽及前两转场；被移出可见区域的模板仍在下拉目录，旧段落 ID 不变。

## 素材与转录

逐小节数据、稳定 ID、Notion 来源及谱面图片 SHA-256 见 `src/data/deepAutumnTemplates.js`。步长为十六分音符；和弦同时起奏但长度不同的音符保留独立时值。第二八度和弦音符在创作音符网格中可见并可编辑。

- 中国鼓律动：原正文写一小节，截图包含两小节；按用户最终确认保留两小节及第二小节差异。
- 摇摆感节奏与非洲舞步：给定截图节奏相同，分别保留名称与 ID。
- 怀旧钢琴：白色播放线遮挡的长音按连续音符处理，不增加一次起音。
- 来源中的 C3、C4、G2、A#2 等音高原样保留，不按曲调名称强行改音。

## 音色

`public/samples/DeepAutumn/` 包含原始 WAV 24 个：鼓 3 个，和弦 21 个（C#、D#、E、F#、G#、A、B × 第 2–4 八度）。源文件名 `#C2` 映射标准音名 `C#2`，资源名用 `CSharp2.wav` 避免 URL 片段误解。文件 SHA-256 与原始文件名见同目录 `manifest.json`，原 WAV 字节未修改。

实时和 WAV 共用音色目录；缺少直接采样的音高按最近采样移调，等距离时与 Tone.Sampler 一样优先较高采样。采样自然尾音保留；鼓按轨道缓存播放器，和弦使用独立 natural sampler，两者进入既有轨道效果通道。新鼓组增益 −3 dB、新和弦 −6 dB，为四轨叠加留余量；旧音色增益不变。
