# 段落编辑：组合 → 保存为 loop

对应需求：[10.8 段落管理](https://app.notion.com/p/3ddd48cb1eee80a085c4cac1abc35b85)。本次为独立本地修正，不推送或发布。

## 使用方式

- 点击四轨 6＋2 宝石模板组合试听，每轨最多一个，再点取消。播放中组合更改在下一小节生效；主段落循环，全转场只播放一次，不返回原组合。
- 模板下方保存按钮自动判定类型：有主乐句为段落，仅选转场为转场；空组合不可保存。
- 保存后停止试听、清空组合，保留音色和 BPM，可继续制作下一条。不再预建空位，也没有 Add、类型选择器、完成编辑或段落管理入口。
- 底部仅展示有内容的已保存 loop，横向滚动且不限数量。点击载入编辑，不自动播放；更新保持 ID，再回到空组合。
- 每条 loop 的“⋯”可重命名或删除，菜单操作不触发播放。自动名称分类递增；改变类型时自动编号名称重算，自定义名称保留。
- 右上角 × 或 Esc 关闭，草稿仅保留在会话内。已有对象各自草稿隔离，不自动保存；保存才更新素材库，Live 已放入的副本不变。
- Launchpad 段落键仅载入已保存 loop，分页、八槽模板、保存与停止沿用现有映射。

## 数据兼容

新组合使用运行时草稿 ID，保存成功才生成持久化 ID。读取 v4 空列表不会回退；旧空白占位过滤，旧有内容、名称、ID 与 Live 副本保留，v1 迁移仍有效。未改变存储格式。保存写入失败保留当前草稿。
