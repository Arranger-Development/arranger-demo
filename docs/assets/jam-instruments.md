# Jam instrument artwork

Four original images generated with the built-in Image Gen tool on 2026-10-15.
These transparent PNGs are shared by the Swiss and hardware skins. No third-party
instrument photograph, brand identity or logo is used.

| Track | Final file | Subject |
|---|---|---|
| Drums | `drums-v1.png` | Walnut bass drum, snare and hi-hat |
| Chord | `chord-v1.png` | Compact vintage electric piano |
| Bass | `bass-v1.png` | Four-string electric bass |
| Melody | `melody-v1.png` | Compact analog synthesizer |

All files are 1254×1254 with an alpha channel. The app uses the complete asset with
`object-fit: contain`, retaining transparent margins and preserving its proportions
through the shared-element transition.

The exact generation prompts and reference relationships are in
[jam-instrument-prompts.json](jam-instrument-prompts.json). Each asset was generated separately, and
all four final outputs were copied into this folder before integration.
