# Jam 旋钮模板与固定槽位

## Launchpad 四行乐句

上方四行从上到下为鼓（Note 81–88）、和弦（71–78）、贝斯（61–68）、旋律（51–58）；每行从左到右对应当前八列分组，使用与屏幕相同的 `slotIndex` 投影。只有含音符的乐句位置亮灯；空位及已创建的空白乐句完全熄灭且不触发，排序、删除和翻组后主动熄灭旧位置。输入解码与灯光共享同一坐标表，等待呼吸、播放稳定亮起，单格继续按轨叠加 / 替换 / 暂停。

下方四行依次为混响、滤波、音量、重复 / 切断 / 刹停；右侧 CC 89／79／69／59 分别多选对应行的效果轨道，CC 93／94 切换八列分组，CC 97 在自动保留模式停用且熄灯，CC 98 总播放 / 停止。沿用现有版本与存储，无需迁移。

## 四轨音量平衡

四轨合奏使用统一的源增益与独立动态控制：深秋鼓组−7 dB、和弦+4 dB、贝斯0 dB、旋律+2 dB；四轨分别进入温和压缩与输出校准，控制密集鼓点和贝斯叠音的响度，同时保留和声与旋律的空间。实时播放、试听、Jam效果输出与整段 / 分块WAV共用 `trackMixBalance.js`；每轨只有一个动态通道，复制轨道独立，效果器重接不会重复叠加。
源音符力度、时值与自然尾音保持，推子仍可微调。“现场效果”标题旁的“平衡四轨”将当前项目四轨推子恢复至校准后的0 dB基础配比，保留静音及效果状态。总输出继续保留原有余量和峰值保护。渲染验证及前后对比见 `docs/jam-mix-balance.md`。

## 单格与整列播放

点击宝石按轨叠加：不同轨道可以同时演奏，同一轨道最多一条乐句。点击其他轨的格子加入合奏；点击同轨新格只替换该轨；再次点击正在播放的格子只暂停这一格。停止状态下启动一格时，历史选择和未保存草稿不会自动加入。
加入与替换在下一小节进入，目标乐句从头开始；暂停在下一十六分步生效。其他轨保留各自起始步、循环进度和自然尾音。再次点击等待格取消等待并保留原乐句；暂停当前格不取消另一格的等待请求。没有播放或等待乐句时才结束总时钟。
列头仍是一次原子请求：下一小节同步启动同列四轨，从头起拍，空位停止对应轨。单格和整列共用逐轨运行状态；每轨的后续请求只覆盖本轨，过期回调不得清除新等待。高亮与等待呼吸由实际音频回调确认，键盘、Launchpad 与鼠标共用入口。
编辑试听临时覆盖输出，后台各轨音乐时钟继续前进；退出恢复原组合的各轨进度，并使用自动保留后的最新内容，不将新建格子擅自加入。音符编辑保留原轨起拍位置，仅释放发生变更的轨。项目数据格式、效果目标和音量平衡保持原样。

## 三轨模板吸附

2026-11-02 按用户确认：和弦 / 贝斯 / 旋律共80个旋钮模板，通过 `src/app/jamPitchedPresets.js` 从原始导入数据派生网页使用版本。起音与结尾吸到最近十六分格，恰好半格向后取整；结尾距下一个小节边界不足一格时，延长到该边界。已有完整一格空白不填满，最短音符为一格；起音与结尾限制在原乐句范围内。和弦0/0第一小节的C#2（内部C#3）由3.85拍变为4拍。

保持音高、力度、音符数量与小节长度，合并同格的不同音高，保留逐音演奏记录；可重复执行而不继续改变结果。模板下拉与旋钮使用同一派生版本，保存、播放与导出继续读取现有音符结构。鼓的连击不参与本次吸附；已保存宝石、现有手工编辑及草稿不会自动重写，重新选择模板或改变旋钮时使用新版。原始ALS和 `dialPitchedPresets.js` 保持原数据及源哈希，源哈希用于核对原始导入，不能代表派生版本的起止时间。

## 音符兼容

Jam 新项目及未指定音色的乐句默认使用深秋鼓组、深秋和弦、深秋贝斯、深秋旋律。界面、新建草稿、保存与播放共用这组默认值；项目或乐句明确保存的音色仍优先保留。旧演奏会话与创作模式的默认音色不变。

音高仍以 `note` / `notes` 表达；可选 `notePerformances` 按音高保存多个 `{ offsetSteps, durationSteps, velocity }`。
界面音名统一使用 Ableton 八度编号：MIDI 60 显示 C3，MIDI 37 显示 C#1。内部音符仍采用音频库的 C4 / C#2 命名，存储、编辑回调、MIDI 和音频事件不做移调；仅在标尺、选中提示、键盘对照、无障碍描述及模板预览处调用 `formatNoteLabel`。此显示转换不可用于保存或播放。
偏移和时值均以十六分步为单位，允许小数；多个记录保留同格同音重复击打。
适配器展开成原有播放事件，以 `gateDuration` 保留按原始时值释放的能力。
旋律的 `playbackMode: natural` 优先播放完整采样尾音，包括导入模板和手工编辑后带有演奏元数据的音符；时值数据继续用于卷帘和 MIDI，不提前截断自然尾音。实时播放、试听、整段和分块 WAV 使用一致规则。
没有该元数据的旧模板继续走原有自然尾音逻辑，非自然模式仍按时值释放；和弦 / 贝斯既有时值规则不变。

改动某格某音时，只将该音规范为一次无偏移的网格事件；其他音的演奏元数据不变。
卷帘显示为十六步网格，已有乐句的演奏信息不因打开编辑器而量化；新选择的旋钮模板按上述规则吸附。WAV / MIDI 导出共享事件适配器。

## 自动保留与位置

模板列表保持紧凑数组，`slotIndex` 是从 0 开始的固定演奏位置，旧项目按原数组顺序初始化。
未标记 `slotLayoutVersion: 1` 的已有项目首次加载时，按每轨原有视觉顺序将已保存乐句连续排到左侧，修复旧删除遗留的空洞，同时更新草稿关联的位置并保留音符、ID、选中状态和混音。仍沿用 v2 存储；升级标记随正常项目保存持久化，只整理一次，之后用户在指定空位新建的位置可正常保留。热更新保留旧项目对象时，也应用同一升级逻辑，删除入口直接使用最新的补位规则。
新建空位立即获得固定ID与 `slotIndex`，可保留空内容；编辑直接原子更新当前乐句、编辑视图和浏览器存储。旧 `targetSlot` 草稿首次进入时转到目标槽位；被占用则移到首个空位，不覆盖其他乐句。详见 [即时编辑与自动保留](jam-live-retention.md)。
更新已有乐句保留原ID、槽位、数组位置与创建时间，不再提供另存入口。删除后，仅同轨中位于删除位置之后的乐句按原显示顺序连续前移补位；删除位置之前的空位和其他三轨保持原位。乐句 ID、音符及演奏信息不变，选择与控制器映射读取更新后的槽位。
编辑视图随乐句更新槽位；自动保留模式下删除乐句同时清理其编辑视图，不再生成脱离原件的草稿或在刷新时复活。删除无关乐句不重新提交播放，播放与等待中的同ID内容更新不重新排队。
连续列表、列播放、键盘、硬件都读取同一槽位投影；列播放使用全局位置，键盘和硬件仍每八列一组。

列表按用户最新确认的密度，桌面主区分配十二列，水平间距至少 16px、轨道间距 14px，宝石尺寸 48–96px；宝石达到上限后将多余宽度分给间距，避免宽屏又塞入十五六列。窄屏维持 48px 最小目标并连续滑动。滚动、硬件分组与尺寸变化均使用实际列宽和间距。宝石及列头拖动用于插入排序；浏览使用触控板横向滚动、滚动条或两侧箭头，不吸附分页。四轨及列头共用滚动区，乐器信息固定在左侧。
编辑器展开时保留相同横向列宽与浏览位置，将上方四轨收成紧凑宝石预览（常规桌面最大56px）；矮屏使用宝石图标与单行名称。编辑器标题栏只保留名称与收起，编辑器自动循环播放，工作台空格键及硬件控制暂停/播放，Escape静音，辅助信息与时值工具同排；600px 高屏幕将小节翻页与撤销放到旋钮下面。编辑器占满剩余高度，卷帘音高视窗以144px为下限随容器增长，鼓格按可用高度适度放大，避免底部大块留白。十六步横轴适配可用宽度，不通过裁掉编辑内容节省空间。1440×900、1280×720、1024×600 四轨编辑器均实测主区无纵向溢出。
末尾始终保留至少八个空位，创建后自动延展。未使用的位置保持纯空白；点击空位立即创建并保留对应宝石，铅笔和叉号位置不变。空白乐句保留在点击位置，点叉直接删除；有内容时沿用确认删除。只有含音符的乐句可触发声音、点亮硬件或显示在创作模式模板库；全空列不显示播放按钮。切轨、换格、收起与刷新均保留最新内容，不经过保存确认。
硬件前后键沿用八列分组，屏幕显示当前映射范围。手动滚动按左侧首个完整可见位置更新分组；硬件切组只将目标范围滚入视野，程序滚动不会反向覆盖它。窄屏优先显示该组开头。
鼠标横移超过 8px 才开始拖动，结束时拦截该次点击；编辑 / 删除控件独立处理。触屏保留浏览器原生横纵滚动。

## 乐句位置排序

鼠标与触屏直接横拖宝石在同轨内插入移动，拖列头则四轨整列一起移动；中间槽位连同空位一起顺移，不自动压紧其他位置。鼠标不再拖动空白区浏览，触屏保留纵向滚动。横向位移超过8px且大于纵向位移才开始排序，轻点仍演奏 / 暂停；编辑和删除工具不参与拖动。

预览显示半透明原宝石、让位动画与插入线，减少动态效果时不播放让位动画；边缘自动滚动可跨越32列及尾部空位。Escape、失焦、窗口尺寸变化、无效落点、指针取消、库内容变化及离开演奏模式取消拖动。Alt＋左右方向键移动聚焦宝石或整列，并跟随焦点揭示目标位置。

一次落点只提交一次位置事务；写入失败回滚整个排序，来源库或项目已变化时拒绝提交。仅修改 `slotIndex` 及编辑视图位置；撤销按乐句ID记录，应用旧内容时始终使用当前槽位；模板数组顺序、ID、音乐数据、保存时间和创作库排序不变。播放和等待按ID跟随，换位不调用播放接口。保存中的草稿仍绑定原乐句，空白草稿跟随同一位置变换，不覆盖其他模板。旧热更新会话若缺少新存储方法，显示刷新提示；刷新后使用完整位置事务。
