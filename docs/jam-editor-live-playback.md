# Jam 编辑器实时播放

2026-11-02，按用户确认取消编辑器试听按钮，四轨共用自动循环。后续即时编辑版本已移除底部播放及所有手动保存入口，当前自动保留规则见 [即时编辑与自动保留](jam-live-retention.md)，音乐模板、采样映射、音量平衡和项目存储格式不变。

## 交互

- 打开含音符的草稿或已保存乐句，从第一小节循环整条乐句。空白草稿不启动新的时钟；添加第一个音符后自动开始。删空后输出静音，补回音符或撤销删除后从头进入。
- 编辑时独奏当前草稿。原合奏的逐轨起点、独立循环及待进入请求保留在底层；切换编辑轨道直接替换独奏，不短暂恢复合奏。关闭编辑器时，若进入前正在合奏且期间没有明确停止，恢复底层组合的已流逝进度；进入前停止的，退出后停止。
- 手工添加、删除、修改时值、撤销及重做，在下一个可调度的十六分步更新，保持原循环起点。旋钮或模板下拉切换整条模板时重置起点及编辑页到第一小节。
- 工作台/音符格上的空格键和硬件总播放键控制当前编辑循环。暂停后修改、换模板、切轨均不自动重新启动；明确播放后从头开始。输入框、滑块及其他按钮保留原有键盘语义。
- 手动暂停会取消退出时自动恢复合奏的资格。点击宝石或列头仍按原叠加/整列规则执行，并结束当前编辑独奏；继续编辑不会擅自抢回播放，底部播放按钮可重新启动编辑循环。
- 小节翻页只改变查看位置；工具栏另外显示实际发声的小节，游标由音频的 `onAudible` 确认。编辑页不会因为调度提前量而提前显示新模板的播放位置。
- 每次编辑自动更新当前宝石及浏览器存储，不再区分待保存草稿与模板。更新保持乐句ID和槽位，不额外重启循环；名称更新不截断声音。

## 播放实现

`jamAudition.js` 管理编辑所有权、暂停意图、是否空白、原合奏恢复资格及编辑版本。`sessionPlayback.audition` 支持明确的 `restart`；从停止进入编辑也使用独奏覆盖层，不把草稿当作底层合奏。原先界面上任何轨道存在等待请求就阻挡草稿更新的条件已移除。

`jamTrackPlayback.js` 对手工更新保留覆盖层的起点，对整条模板更新重设起点。底层等待请求在独奏期间仍按时钟推进，但不会截断编辑声音；恢复后才按实际发声确认并清除等待。覆盖层版本阻止旧回调覆盖新的编辑或恢复已暂停的状态。编辑版本仅存在于运行态，不写入项目或乐句数据。

准备音色期间退出或暂停会使旧启动请求失效。音频加载失败保留错误及草稿，并将编辑停在暂停状态；继续编辑不会自动重试启动，用户可明确播放重试。

## 验证

- 新增12项音乐时钟测试，覆盖四轨自动循环、空白/首音/清空/撤销、手工编辑保留起点、同乐句ID切换模板重新起拍、暂停意图、编辑切轨、合奏恢复、等待请求与延音、过期回调、启动取消和加载失败。使用真实导入的和弦模板核对首步事件的音高、力度、时值与偏移。
- 实际浏览器与音频通过四轨自动播放、移除试听按钮、音符格空格暂停、暂停后编辑保持静音、模板从第一小节进入、手工更新不重新起拍、整列合奏恢复、暂停后退出不自动恢复、空白首音、删空、撤销恢复以及手动保存后的继续播放。
- 独立内存项目验证未保存编辑不覆盖原模板；四种尺寸1440×900、1280×720、1024×600及720×900均无编辑器自身纵向溢出，保存入口可达。记录与截图在 `output/playwright/jam-editor-live/`。
- `npm test` 977项通过；`npm run lint`、`npm run build`、`git diff --check`通过。构建保留原有的大体积包提示。
