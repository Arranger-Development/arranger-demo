# Jam 即时编辑与自动保留

2026-11-02，用户确认取消保存修改、保存新模板、另存、保存项目和底部播放按钮。乐句编辑即当前内容，保留宝石/整列触发、空格、Escape及硬件播放；保存键不重新绑定。正常编辑没有保存提示、草稿标签或切换确认。

## 内容与持久化

- `commitPhraseEdit(draft, { projectId, create, slotIndex })` 一次事务更新乐句、兼容编辑视图和localStorage。每次有效音符/时值/音型/旋钮档位/名称修改立即写入，不等待收起或切轨。没有双写“草稿再保存模板”的中间状态。
- 创建时分配固定ID和槽位，空白也保留。后续编辑只更新同一ID，不改变槽位、数组顺序及创建时间 `savedAt`，旧模板没有创建时间也不因首次编辑改变创作库排序。旧字段、逐音演奏元数据及音高/采样映射不被重写。
- 返回值是最新内存乐句，非法ID、位置或过期项目返回null；写入是否成功需读取store的 `error`。写入失败仍保留最新内存数据，提示不可刷新并提供重试；项目切换/离开前重试失败则停留当前项目。恢复成功后一次写入所有最新内容，不宣称失败的数据已持久化。
- 存储根版本仍为v2，工作区增加可选 `liveEditingVersion: 1`。`enableLiveEditing()` 首次进入转换旧草稿，活动编辑视图优先于同轨旧缓存：绑定已有乐句的脏草稿更新原ID；新草稿转到原位置，冲突时选首个空位；空草稿也保留。转换前的原乐句通过 `takeMigrationHistory()` 作为本次会话撤销基线；重复进入不重复转换。
- 自动保留模式删除乐句时清理关联编辑视图，防止刷新复活；原有补位和含音符确认删除继续沿用。空块点叉直接删除。没有内容的块仍占槽位，但不启动声音、不亮乐句灯、不进入创作模板库；全空列没有播放按钮，未使用的位置继续留白。

## 撤销与手势

`createJamPhraseHistory` 以项目ID和乐句ID管理最近50次撤销/重做，完全在内存中。换轨、换格、收起、切项目仍保留对应历史；刷新读取最新内容且历史清空。

音符操作分别记录；旋钮拖动、MIDI连续手势和连续名称输入各合并为一次。MIDI以300ms无后续变化结束；在手势结束前撤销也可恢复完整手工内容。不同操作类型不会合并，旋钮后立即点音符先结束旋钮历史，再记录音符修改。自动写入、运行态元数据和字段顺序变化不产生历史；新编辑清除对应重做分支。应用撤销始终保留当前ID、槽位及创建时间，拖动排序后撤销内容不会搬回旧位置。

## 音频与硬件

`sessionPlayback.updatePhrase(snapshot, trackId, id)` 只更新底层当前乐句及待进入同ID内容，使用下一可调度十六分步，保留起点、循环长度规则和等待边界。提前准备的旧回调不能覆盖新版本；取消已准备的替换会恢复原乐句最新的自动保留内容。更新不会启动停止的时钟、重新排队其他轨或把新格子加入原组合。

编辑独奏继续由原覆盖层驱动：手工修改/撤销保留进度，换整条音型从头开始；收起后原组合使用更新后的内容及原逐轨进度。清空时静音但保留格子，撤销可恢复；无编辑覆盖且没有非空播放或等待项时结束总时钟。名称编辑及名称撤销不改音频或截断尾音。显式暂停仍优先，后续修改不会擅自启动。

列头按钮随状态切换：空闲为播放图标，等待或播放时为暂停图标。再次点击当前播放或等待的列立即暂停总播放并取消待进入请求，图标恢复播放；再次点击从乐句起点启动该列。暂停不删除格子或选择。程序调用 `launchJamColumn` 默认仍为幂等启动，界面使用 `toggle:true` 开启此交互。

输入解码与灯光都排除空块，不压紧槽位映射。界面声明 `manualSave:false`、`canSave:false`，CC97输入停用且正常/存储失败时均熄灯；其余四行乐句映射、效果控制、翻组和总播放键保持原绑定。
