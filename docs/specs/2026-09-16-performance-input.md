# 演奏模式输入

适用于普通风格及 AI 演奏模板。鼠标、键盘、Launchpad 共用草稿和保存状态，不改变模板或浏览器保存格式。

## 电脑键盘

| 轨道 | 模板从左到右 |
| --- | --- |
| 鼓 | 1 2 3 4 5 6 |
| 和弦 | Q W E R T Y |
| 贝斯 | A S D F G H |
| 旋律 | Z X C V B N |

只有实际存在的模板可触发。按下选择／再次按下取消，松开不改变选择，长按不重复操作。物理键位通过 `KeyboardEvent.code` 识别；忽略修饰键、输入法组合输入和可编辑控件中的输入。键盘不增加 Loop、保存、播放快捷键，保留聚焦按钮的原生键盘操作。

## Launchpad X

手动进入 Programmer Mode，在演奏页点击「连接 Launchpad」。使用现有 MIDI 端口，不请求 SysEx。

从设备顶部计数：第 1–4 排分别对应鼓、和弦、贝斯、旋律，每排从左开始排列；第 5–6 排留空。第 7 排为八格进度灯。第 8 排第 1–5 格为 Loop 1–5，第 6 格空，第 7 格保存，第 8 格播放／停止。外围按键在演奏模式不执行编曲命令。

模板选中高亮，未选暗亮。Loop 区分空位、已保存、当前编辑和随实际节拍闪动的播放位置。保存成功短暂绿色，失败红色。播放／试听中播放键为红色，停止为绿色，加载中闪红且可取消。进度使用音频时钟，根据当前两／四小节段长显示；加载、停止时清零。

模式切换清理硬件按住状态和待处理手势。返回编曲恢复原映射。断开设备保留草稿及音乐，重连刷新全部灯光；正常运行只发送有变化的灯光。

## 实现与验证

- `performanceEditor` 提供同步快照，避免 React 批量更新时连续输入覆盖前一次选择。
- MIDI 由现有单一连接独占路由到当前模式；演奏输入在普通编曲手势和映射之前处理。
- `performance_input.test.js` 覆盖两类模板组映射、边界输入、草稿保存、灯光差分与时钟同步；已有播放测试覆盖快速切换和加载取消。
- 浏览器验证覆盖混合输入、MIDI 热插拔、两／四小节切段、编曲隔离和返回、三种屏幕尺寸。
- 真实设备需要另外确认 Programmer Mode 下的实际灯色和响应。模拟 MIDI 验证不能代替实体设备验收。

仅本地实现；无自动提交、推送或部署。
