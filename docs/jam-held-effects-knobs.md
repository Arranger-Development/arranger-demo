# 按住效果器时的旋钮更新

分支：`fix/jam-held-effects-knobs`。经用户确认，本轮提交并发布到 Development 预览站；保留其他工作区已有改动，对外演示站不更新。

## 行为

- 按住 Repeater、Chopper 或刹停时，效果目标轨的旋钮修改立即显示、自动保存并保留撤销记录，但暂缓音频更新。其他轨正常编辑。
- 待应用内容按项目、播放会话、轨道及乐句 ID 关联，只保留最终参数；切换或收起编辑器后仍应用原乐句。新空乐句生成内容后，编辑器状态也同步保留。
- 最后一个相关效果松开时，由音频调度器在下一可调度十六分音符同时解除效果并应用修改。原播放起点保持，新循环长度按该起点计算；未加入的轨道仍按原下一小节规则进入。
- 旋钮更新只释放旧音符，不清空效果缓存。快速重按会取消旧待执行释放，旧持有者的松开不能结束新效果。弯音不参与延后保护。
- 明确选择其他乐句块、音符/音型等显式内容修改维持原有规则，并取消相关旧待应用内容。暂停、停止、删除、加载失败及工程切换不会因晚到的松开事件重新启动。
- 贝斯、旋律压缩后输出分别从 −8/−1 dB 提高到 −7/0 dB；用户推子与静音不改写，播放和 WAV 渲染共用校准。

## 验收

新增模型回归覆盖四轨与三种效果全部档位、连续两旋钮修改、效果叠加、多目标与非目标轨、快速重按、编辑器切换/收起、循环长度变化、新空乐句、排队边界、明确切换乐句、显式音符修改、停止、删除、加载失败及工程切换。音频引擎回归验证释放时间、旧音符释放与效果缓存保留的区别，共享混音验证新输出校准。

最终代码完整测试 1111 项通过，lint、build 与 `git diff --check` 通过。构建保留已有的大包提示。

独立原生尺寸浏览器通过鼠标、键盘及模拟 Launchpad/旋钮 MIDI 验证四轨：按住时保存的参数改变，但调度矩阵、播放起点与声部释放次数保持；松开后最终内容生效，整个合奏仅一次启动。Repeater 保持有声；刹停过程中调整参数后的目标轨峰值约为 1.40×10⁻¹⁵，未出现新干声；停止后峰值为 0。

稀疏、常用、密集与鼓推子 +6 dB 压力场景的真实 WAV 渲染均无削波。浏览器使用独立窗口，验收结束关闭，不保留视口模拟。

本轮未连接实体设备。此前“Launchpad 跟随后实体旋钮编辑对象可能仍为上一个乐句”的问题仍单独保留，本轮不将其记为已修复。
